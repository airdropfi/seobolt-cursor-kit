# Example prompts

Paste any of these into Cursor (Agent) after the `seobolt` server shows a green dot in Settings, then MCP. The first four are read-only.

1. `Use SEOBolt to list my projects with their health scores.`
2. `Show the SEOBolt audit for <my domain>: health score, issues grouped by type, and Core Web Vitals.`
3. `How hard is it to rank for "<my keyword>"? Show the top results with their Domain Ratings.`
4. `Which pages of <my domain> does Search Console say I rank for but don't target on-page? Needs Search Console connected in SEOBolt and a Pro plan or above.`
5. `Get the SEOBolt fix plan for <my domain>, tell me which files in this repo each fix touches, and show me the diff for the first three before you change anything.`
6. `I deployed the fixes. Start a new SEOBolt crawl and compare the health score with the previous one.` (starts a real crawl; it counts against your plan's crawl allowance)
